Hey, I'm Asish Ranjan Sahu

I'm an engineering student who builds things I actually want to use: writing tools that feel like paper, a voice companion that runs entirely on my laptop, and a short film I made on my own.

One question follows me into every project: does this need to exist?

Right now I'm going deeper into networking and security, learning Linux, Bash, and how the web works underneath. I'm also in a full-stack program at Project School.

Things I've made
Tools that feel physical

Paper: an offline writing space with synthesized mechanical-keyboard sounds, paper grain, and a folding-fan (Sensu) card deck you navigate with trackpad gestures. I wanted typing to feel like something. javascript web-audio-api

Screened: a screenwriting tool with proper industry pagination and nothing else on screen. javascript typography

Joi: a voice-first AI companion inspired by Blade Runner 2049. A dark screen, a softly breathing audio-reactive core, and local models through Ollama, so nothing leaves my machine. python fastapi ollama sqlite

Security & hardware

Sifter: my hackathon project (cybersecurity track). Paste in a link or a message and it gives you a trust score, so you can tell if something is a scam before you click. security

ENCLAVE: an Android sandbox that isolates apps and keeps permissions in the user's hands. kotlin android

Sentinel SOS: an emergency app that detects a hard impact, sends your GPS location, and falls back to SMS. I'd never touched Android before this, and I shipped it anyway. kotlin gps sensors

DEQUEUED: a smart shopping cart that checks the barcode scan against a load-cell weight reading, so things can't quietly walk out of the store. iot embedded

Stories

All Ends Die: Part One: a quiet sci-fi short I wrote, shot, and edited myself. Twilight skies, tangled trees, and a lot of patience.

The Exodus Project (4657 AD): the novel I keep coming back to. Thirty chapters about humanity migrating across seven planets after the sun expands, with an invented language and a long war between science and made-up religion.
